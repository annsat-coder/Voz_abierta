# Voz Abierta

Proyecto web independiente de una plataforma ficticia de discusión ciudadana.

## Archivos
- `index.html`: estructura de la interfaz.
- `style.css`: estilos, responsive y componentes visuales.
- `script.js`: publicaciones, búsqueda, ordenamiento, votos, guardados, comentarios y modal de creación.

## Imagen de Ancón
Coloca `foro-cenisur.jpg` directamente junto a `index.html`, `style.css` y `script.js`.

La publicación de Ancón está preparada para mostrar ese archivo. Si todavía no existe, la página seguirá funcionando y mostrará un aviso dentro del espacio de imagen.

## Cómo abrir
1. Descarga/descomprime la carpeta.
2. Coloca `foro-cenisur.jpg` en la raíz.
3. Abre `index.html` en un navegador moderno.

No requiere servidor ni backend.
